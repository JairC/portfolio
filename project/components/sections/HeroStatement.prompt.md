# HeroStatement

Home hero: a 96px Fraunces statement, mono intro plus meta grid, then actions.

```jsx
<HeroStatement intro="Designer and consultant." meta={[["ROLE","PRODUCT DESIGN / UX"],["BASE",null,true]]} actions={<Button>CONTACT →</Button>}>Strategy first.</HeroStatement>
```

Italic Fraunces 400 is the only emphasis allowed inside the statement. Mobile drops to 44px.
