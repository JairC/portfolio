# Button

Square mono-label action. Primary is solid ink, outline is a 1px inset hairline.

```jsx
<Button variant="primary" href="/contact">CONTACT →</Button>
<Button variant="outline">DOWNLOAD CV ↓</Button>
```

Never rounded. Primary hovers to red (--button-fill-hover); outline hovers to solid ink. Labels are uppercase mono with an arrow glyph, never an icon.
